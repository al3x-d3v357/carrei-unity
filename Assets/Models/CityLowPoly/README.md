## Como importar no Unity
1. Extraia o .zip baixado
2. Arraste a pasta para Assets/Models/CityLowPoly/
3. Unity importa automaticamente FBX/OBJ/GLTF
4. Arraste os modelos para a cena

## Formatos recomendados
- Unity: FBX ou GLTF
- Godot: GLTF/GLB
- Blender: FBX ou OBJ
