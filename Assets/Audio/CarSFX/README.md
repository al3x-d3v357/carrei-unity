## Formato recomendado
- Sons curtos de impacto (freio, skid, turbo): WAV
- Loops de motor/aceleração: OGG ou MP3

## Dica Unity
- AudioSource.loop = true para motor
- AudioSource.PlayOneShot() para freio/skid/turbo
- pitch dinâmico: audioSource.pitch = 1.0f + speed * 0.5f;
