## Como importar no Unity
1. Extraia o .zip baixado
2. Arraste a pasta para Assets/UI/Icons/
3. Selecione os PNGs → Inspector → Texture Type: Sprite (2D and UI)
4. Filter Mode: Bilinear, Compression: None, Mip Maps: Off

## Dica
- Use SVG para ícones escaláveis (pacote com.unity.vectorgraphics)
- Use PNG 256px para compatibilidade máxima
- Textura branca + tint = uma textura serve para todos os estados de UI
